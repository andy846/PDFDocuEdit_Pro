# PDFDocuEdit Pro v2.5.13

Quick fix for Deep Search result opening and previews.

- Fix filename-header sorting discarding result identity, which prevented opening files and displaying previews.
- Fix Open Selected Document interpreting the button click as row zero and opening the wrong file.
- Populate the first result preview automatically and refresh it when the current result changes.
- Preserve custom data, styling and item flags in shared sortable tables.

## Update

Existing Managed Portable installations: Help > Check for Updates > Download Update > Update and Restart.

For a new deployment, extract the complete Managed Portable ZIP into a new writable folder and run Launcher.exe. Do not extract it over an existing deployment.

Signed update manifests and matching ZIP SHA-256 checksums are included.
