# PDFDocuEdit Pro v2.5.15

This release adds an on-screen ruler for PDFs.

- Click two points to measure the straight-line distance at the PDF's defined paper size. The default unit is millimetres; centimetres are available from the context menu.
- Keep several temporary measurements on each page. They remain aligned when zooming, rotating, or navigating pages, and disappear when the document closes.
- Save a selected measurement as a PDF line annotation with a visible distance label. Save the document to retain it after reopening.

Measurements use the PDF page's physical dimensions, including its `UserUnit`. They do not infer a drawing or map scale. A print dialog's scaling option can change the length on printed paper.

## Install or update

For a new Windows x64 installation, run `PDFDocuEdit-Pro-v2.5.15-Setup-Windows-x64.exe` or extract the Managed Portable ZIP and start `Launcher.exe`. Existing managed installations can use Help > Check for Updates > Download Update > Update and Restart.

The signed update ZIP and manifest are for existing managed installations. SHA-256 files are provided for the installer and both ZIP packages. This Setup EXE is not Authenticode-signed; verify its SHA-256 checksum.
